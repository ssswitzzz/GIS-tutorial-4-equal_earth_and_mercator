# 配音定时版

以 `4 视频配音/4 视频配音.srt` 全文为依据，按语义场景调整动画，不逐条跟随自动字幕的断句。此文档取代各章设计稿中的估算时长。

| 入口 | 整片范围 | 帧数（60fps） |
| --- | --- | --- |
| EqualEarthIntro | 00:00.000–00:51.660 | 3100 |
| PerfectMapFilm | 00:51.660–02:54.500 | 7370 |
| MercatorFilm | 02:54.500–05:13.620 | 8347 |
| EqualEarthFilm | 05:13.620–07:53.740 | 9607 |
| OutroFilm | 07:53.740–08:33.640 | 2394 |
| FullFilm | 00:00.000–08:33.640 | 30818 |

时间统一存放在 `src/narration.ts`。每个锚点分别记录原动画秒数、整片配音秒数。场景内部保持原动作顺序；`AnimationClock` 与 `useAnimationFrame` 向所有动画子组件提供独立的设计时钟，允许设计时间超过缩短后的章节长度。已移除会被 Remotion 章节长度截断的 `Freeze` 映射，修复平等地球约 2:04 后停住以及其他章节后半段的同类问题。音轨位于映射外，保持原速。章节边界先按整片绝对时间四舍五入成帧，再相减，避免逐章取整造成缝隙。

细分锚点中的 422.50、437.10 秒是同一语义场景内部的视觉分拍，并非强行对应字幕断句。原章节 timing 文件与旧数学检查输出仍表示设计时钟，不表示实际播放时长。

完整配音复制到 `public/audio/narration.wav`。各独立章节自动裁取对应音频；整片只有一条连续音轨。原录音、SRT 和旧 intro.wav 保留。

## 结尾设计

| 局部秒数 | 内容 | 动作 |
| --- | --- | --- |
| 0–11.37 | 各有所长，各得其所 | 平等地球连续变为墨卡托，直线航路绘制与航向标移动 |
| 11.37–19.46 | 让大陆回到真实比例 | 墨卡托连续变回等面积地图，底部基线展开 |
| 19.46–31.94 | 理解选择，读懂地图 | 世界地图轻缓转动，收束用途与取舍 |
| 31.94–39.90 | 感谢、关注、三连、再见 | 地图缩向右侧，左侧告别文字入场，三连标记依次描边 |

结尾沿用纸张、思源宋体、墨绿陆地、蓝色航线。没有新增长篇字幕。

## 预览与自行导出

现有预览： http://localhost:3004/FullFilm ，结尾： http://localhost:3004/OutroFilm 。

在 `remotion-video` 目录执行：

```powershell
npm.cmd run dev -- --port 3004
npx.cmd remotion render src/index.ts FullFilm out/full-film-1080p60.mp4 --codec=h264 --crf=18
npx.cmd remotion render src/index.ts OutroFilm out/outro-1080p60.mp4 --codec=h264 --crf=18
```

所有章节与整片的默认输出统一为 1920×1080、60fps，时长与配音同步保持不变。此设置取代早期设计稿中的 4K 输出规格。没有导出最终视频。

验证：`npx.cmd tsc --noEmit`；`scripts/verify-narration.cjs` 检查 SRT 总长、帧数连续性、时间映射、各场景排版、三维画布运动和随机访问确定性、手机预览与整片章节时钟。
